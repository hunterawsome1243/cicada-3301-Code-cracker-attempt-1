## Lessons

- 2026-10-28, rehearsal (instrument, own lane): the P3 PREREG froze its family-wise bar as `threshold_for`'s four-decimal print (−5.7284). The value is −5.72837932, so the frozen bar sat 2.07e-5 below it, and `runeforge lane` refuses a bar below `threshold_for` (−1e-6 tolerance). The lane would have been refused at the moment TR-1 made it runnable, and the ledger cannot change a frozen threshold. It was found only by running the whole install → lane → control → preflight chain in a disposable clone before Hunter did. Fix: re-registered as `P3-MT19937-PY27-ANTIREPEAT` with the bars rounded up (−5.728379, −6.043391). Rule from it: freeze bars from `threshold_for --json`, rounded toward the conservative side (up for a bar), never from the human-readable print, and rehearse a lane's run path in a disposable clone before it goes to `queue.json`.
- 2026-10-28, red-team (FOUND-ERROR, own claims; `lanes/R1-REDTEAM-OWN-CLAIMS/RESULTS.md`): every instrument number re-derived with independent code reproduced (Witten-Bell power and bars, KN order 4 to 1.1e-16, the P3 control 20/20 with an independent MT19937 / plant / beam, the P3 bars to 1e-4). What failed was prose that crossed contexts: the P3 PREREG quoted a vowel-dropped power measured under another decoder and bar (0.790 rigid; the lane's own is 0.595 [0.526, 0.661]), and the upstream overlap was called "0 claim-bar hits" when upstream's files hold an unresolved flag (seed 35563892; −6.4894 under P3, below both bars). Rule from it: a conditional quoted into a lane must be measured at that lane's decoder and bar, and an upstream count is quoted with the upstream file's own caveats. Also measured: the reduced-scale bootstrap intervals understate seed-to-seed bar variance (kn4-cicada L = 240: the report's bar is a 3rd-percentile draw), so cells near a bar wait for `--full`.
- 2026-10-22, instrument (FOUND-ERROR, own toolbox): `interrupt_prob` defaulted to 0.44, reading "WELCOME 11 of 25" as P(a plaintext F is an interrupter). It counts ciphertext ᚠ's; every plaintext F in the keyed solved sections is an interrupter (14/14). Default corrected to 1.0 (`runeforge/lanes.py`); frozen docstrings carry the same misreading (TR-4). Consequence, measured: under the every-F rule the template lane's family fails the gate on C1 in 12/12 keys (`python scripts/beam_power.py`, gate section). LP2 0-55 holds 458 ᚠ against 446.8 for uniform runes, where English-register plaintext with every F unencrypted would put ~650-780. So under the every-F rule (1.0) the family fails C1 on 12/12 keys; `interrupt_prob: 0.0` passes cleanly and 0.1 and 0.44 pass marginally (C3 on 2 and 3 of 12; `reports/beam_decoder.md` §3); the template lane uses 0.0; the earlier "GATE PASS, marginal C3" below was measured at the misread 0.44.
- 2026-10-22, instrument: the spec's "rigid screen, beam on survivors" cannot see a filtered key -- a rigid decode of a planted anti-repeat key scores like noise (control 0/20), so it never reaches the survivors. Rule 2 (the control runs the sweep's own pipeline) puts the beam in the screen itself: a `:beam*` lane decodes every key with the beam in its control, nulls and sweep. CPU cost ~1,000-2,500 keys/s at L = 240 (beam ~2,500, beam-skip ~1,240, beam-skip-int ~1,000) against about 10^5 rigid (`reports/beam_decoder.md` §6, noise).
- 2026-10-22, calibration: a beam lifts wrong-key noise above uniform strings (it picks the best interrupt/skip path through the wrong key): at L = 240 with lp-ngram3-heldout the wrong-key mean is -6.90 (beam), -6.87 (beam-skip), -6.74 (beam-skip-int) against -7.17 rigid (`scripts/beam_power.py` noise). Beam bars therefore come from beam nulls (`runeforge/scoring/beam_calib.py`), never from the rigid calibrations.
- 2026-10-22, calibration (adversarial review): an interrupt decoder's wrong-key null rises with the window's canonical F count (`beam`, L = 240: block-max mean -6.57 at 4 F's, -6.32 at 20, `scripts/beam_power.py` fcount; `beam-skip` flat), so a bar fitted on fresh uniform ciphers sits below an F-rich window's own null. `beam` / `beam-skip-int` bars are fitted at the most F's of any LP2 page-start window (L = 120: 10, page 43; L = 240: 14, page 11) and a lane whose window holds more is not runnable. The first-round fits (uniform ciphers, max_skip 2) were withdrawn before anyone installed them.

Every lane today therefore ends `EXCLUDED (gate)` or `INCONCLUSIVE (power)`; the Phase 2 beam decoder is the critical path, not more sweeping.
