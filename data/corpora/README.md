# Corpora

Transliterated plaintext in rune space (indices 0–28, Gematria Primus order) with a word id per
rune, for the fingerprint gate (`runeforge gate`), positive controls (`corpus:<name>`) and the
scorer presets. Everything in this directory except this README is generated by
`scripts/build_corpus.py`, gitignored, deterministic, and never hand-edited:

```
python scripts/build_corpus.py            # all corpora (about 3 s, offline)
python scripts/build_corpus.py --list     # the SOURCES table
```

Read them with `runeforge.corpus`: `load(name)` returns `Corpus(runes, word_ids, meta)`;
`english_stream(n, name="cicada-english", offset=0)` returns exactly `n` runes with word ids from 0
(it raises if the corpus is shorter). A missing file raises `CorpusMissingError` naming the build
command. The corpus and fingerprint tests build every corpus into a tmp dir on the fly; the
calibration test of the corpus-trained presets reads data/corpora/ and skips locally until
`scripts/build_corpus.py` has run (CI builds it first).

## Output

| file | contents |
|---|---|
| `<name>.npz` | `runes` (int8), `word_ids` (int32, consecutive from 0), `meta` (the JSON index entry) |
| `index.json` | per corpus: name, register, language, n_runes, n_words, `indices_sha256` (comma-joined indices, the canon pin convention), sources (vendored path, pinned SHA-256, the cut rule), transliteration rules, note; top level `numbering: "LP2-0-57"` |

## Transliteration

1. Cut the body (literal start marker, which must occur once; end marker, first occurrence after it;
   optional drop spans and a line filter), then normalise: Unicode NFKD with combining marks removed
   (ē → e, ǣ → æ), then Æ → AE, Œ → OE, Þ/Ð → TH, ß → SS, ſ → S, Ƿ → W.
2. Words are maximal runs of A–Z after upper-casing; every other character separates words, so an
   apostrophe or hyphen splits a word (`LAMB'S` → `LAMB`, `S`, as murphy's `english_stream`), and
   any letter outside A–Z (Greek quotations in Emerson) is a separator; its count is recorded as
   `non_latin_letters_dropped`.
3. Each word is spelt with `runeforge.gematria.DEFAULT_RULES` (substitutions QU→CW, Q→C, K→C, V→U,
   Z→S, then greedy longest-match graphemes ING/NG, TH, EO, OE, AE, IA/IO, EA, single letters),
   exactly as `gematria.transliterate_words`, memoised per distinct word. Matching never crosses a
   word boundary. Old English maps natively onto the futhorc (æ → ᚫ, þ/ð → ᚦ, ea → ᛠ, eo → ᛇ).

**vowel-dropped-english**: from the `english-general` arrays, remove every vowel rune — U, O, I, E,
A, Y and the vowel digraph runes EO, OE, AE, IA, EA (indices 1, 3, 10, 12, 18, 22, 24, 25, 26, 27,
28) — except a word's first rune. No word vanishes (`A`, `I`, `OF` → `A`, `I`, `OF`: F is not a vowel rune) and the word ids
are unchanged. U is also V in rune space, so `LOVE` → `L`.

## not_covered (Phase 2 extends SOURCES)

Signed Cicada messages, Liber AL, Blake and the Mabinogion (Cicada register), Project Gutenberg
English beyond Moby-Dick, the Latin Vulgate, Welsh and the Old English Rune Poem are not built.
Adding one is a `Spec` row in `scripts/build_corpus.py` plus its path in `scripts/fetch_raw.sh`.
